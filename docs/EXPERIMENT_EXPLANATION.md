## 1. 一頁摘要

### 研究問題與白話結論

我們最後希望用聲音估計體脂率，但目前先問一個較能驗證的問題：在 NISP 的新說話者上，語音是否能提供年齡、性別之外的身體資訊？NISP 是本研究使用的語音資料集；現階段目標是身高與 BMI。BMI 是身體質量指數，由身高、體重計算，用來描述相對體重，並非直接量到的脂肪比例。

在預先鎖定的 test（測試集，也就是不參與模型或參數選擇的受試者）上，BMI 的額外預測增益獲得支持；身高的額外增益尚未確認。這裡的「成立」只指既定資料、切分、模型與判斷門檻下的結果，不代表已完成體脂率估計，也不代表找到了聲音與脂肪的生理因果關係。

主要指標是 MAE，即平均絕對誤差：把每個人的預測與實際值相差多少取絕對值，再平均。BMI 的人口基準 MAE 為 2.733386 kg/m²，選定語音模型為 2.407814，既有報告記載降低 0.325572，約 11.9%。身高則從 5.135488 降為 5.042051 cm，降低 0.093436 cm。後者雖有較好的點估計，但不足以確認改善。

成對 bootstrap 是把同一批人有放回地重抽，並在同一份抽樣上比較模型的方法，用來描述結果對受試者組成變動的敏感程度。BMI 的成對誤差差區間完全低於零，且通過預先設定的兩目標多重比較門檻；身高區間跨零，因此改善與惡化都仍與這份資料相容。信賴區間是固定方法所給的不確定性範圍，不是保證未來每次訓練都有同樣結果。

### 最重要的三個限制

- **目標不同：** BMI 不是體脂率，身高也不是體脂率；現有結論不能直接移植到最終目標。
- **訊號來源未釐清：** 語音特徵可能同時包含母語、麥克風通道與錄音條件。分組改善不均，不能只用整體平均宣稱捕捉到身體本身。
- **證據範圍有限：** 這是單一資料集、有限說話者上的固定模型評估。區間沒有涵蓋重新訓練與完整選擇的不確定性；test 已使用，不能再拿來調參。

資料與結果來源：S0、S6。

## 2. 研究動機與問題

以聲音估計身體資訊的吸引力，在於錄音取得方便，可能成為低成本的輔助量測。但聲音與身體指標即使相關，也不表示錄音能取代真正量測。開始時若直接使用複雜神經網路，資料對齊、評估切分與模型效用會混在一起，難以知道成功或失敗的原因。因此本專案先保存固定語音特徵，使用可解釋的基準與回歸，把資料流程及比較方式逐步做乾淨。

「年齡＋性別」基準是必要的。聲音容易攜帶性別訊號，而身體指標也可能隨性別、年齡改變。若模型只擊敗平均值，它可能只是先辨認性別，再猜該群常見的身高或 BMI，並沒有增加人口資訊以外的預測能力。主要問題因此不是「聲音能不能猜到某個數值」，而是「已經知道年齡、性別後，聲音還能否降低誤差」。

同一目標的語音＋人口模型與人口基準，使用相同受試者、相同分折及相同人口項，才能針對這個問題比較。純語音模型仍有診斷價值，可以看出特徵本身的預測能力；但純語音擊敗常數模型，不足以回答額外資訊的問題。人口基準也不是完美的生理模型，其作用是提供共同、透明且可重現的比較起點。

本研究分別預測 BMI 與身高。身高作為輔助對照，可以檢查流程是否在另一個已知標籤上有訊號，但它不是必定成功的陽性證明。加入人口資訊後仍未看到身高增益，可能是條件訊號弱、資料或模型有限，不能直接判定程式錯誤。真正體脂率資料仍待取得，屆時需要獨立驗證。來源：S0、S3。

## 3. 資料與分析單位

本次使用 NISP 的 14,691 段英文錄音、345 位說話者，保留既有 train（訓練集）168 人、validation（驗證集）42 人、test 135 人。train 用來擬合模型；validation 在第一批用來選參數；test 留到設定固定後，評估未參與開發的新說話者。第二批把原 train 與 validation 合為 210 人的 development（開發資料），在其中交叉驗證。

**切分、擬合、誤差與重抽樣的基本單位都是人。** 同一人的多段錄音對應相同身體標籤，不能把它們當成彼此獨立的受試者。若同一人的片段同時出現在訓練與評分集合，模型可能利用聲音身份線索，看起來能預測新錄音，實際上沒有驗證新人的泛化能力。以說話者切分，可以避免這種直接捷徑。

錄音多不等於有同樣多獨立標籤。特徵先以 speaker ID（說話者識別碼）與標籤對齊，再形成一人一列的資料。ID 用於對應，不是模型輸入。身高、體重與 BMI 也不作為預測輸入，尤其不能把計算 BMI 所需的身高、體重餵給 BMI 模型，再稱為從聲音預測。

BMI 的定義為體重公斤除以身高公尺的平方。這是衍生標籤，不是直接量到的體脂率。指定摘要並未完整交代原始身高、體重的量測工具、是否自報及誤差，因此本文件不替資料來源補上這些假設。

錄音均使用英文，分組表中的 Hin、Kan、Mal、Tam、Tel 是 NISP 說話者的母語群代碼，並不是本次英文與其他錄音語言的比較。同樣使用英文，也不保證口音、收音設備、地點或背景相同。來源：S0、S1、S6。

## 4. 語音特徵與平均方式

### 凍結 WavLM

WavLM 是事先訓練好的語音模型，可以把波形轉成數值表徵。其 SSL（自監督學習）指從語音本身建立學習訊號，不必為每段預訓練錄音提供本專案的身體標籤。「凍結」表示本次不更新它的權重；只把它當作固定特徵產生器，不從 NISP 從頭訓練或微調。

保存的是 WavLM Base+ 的 12 個 Transformer 層。Transformer 是利用序列中不同位置資訊建立表徵的模型結構；每層提供不同處理階段的結果。每層 768 維，表示一個人的該層輸入有 768 個數值，並不是總共只有 12 個特徵。層索引對應 Transformer 層，embedding（初始輸入表徵）層不列入這次層比較。

### MFCC 與共同前處理

MFCC 是梅爾頻率倒譜係數，用較少數值描述語音頻譜的形狀，是傳統聲學特徵。這次取 13 個係數的時間平均及標準差，形成 26 維；標準差描述該段內係數如何隨時間變動。這個基準不是包含所有傳統聲學特徵的完整系統，基頻沒有納入本輪實作。

兩種特徵使用相同音訊截取。每段取最多前 10 秒，不足則使用全段，並從實際 44.1 或 48 kHz 重採樣至 16 kHz。重採樣是調整每秒樣本數，讓模型看到符合固定規格的波形；不只是改寫檔案的取樣率標籤。

WavLM 在一段音訊內先沿時間平均，將隨時間變化的向量變成固定長度向量；MFCC 則保留上述平均及標準差。接著對同一人的各段錄音**等權平均**。每段錄音對該人的平均貢獻相同，最終每個人對回歸與評分也等權。這種整理降低後續計算量，但同時捨去時間順序及部分段落差異，是方法的取捨。

全部層已保存，所以比較層不需要再次提取特徵。每次層比較只取一層的 768 維，沒有把各層串接。特徵固定不代表後續前處理也能看完整資料：標準化仍只能使用當次訓練集合的統計量。來源：S0、S1、S3、S7。

## 5. 方法與防止偏差的規則

### 回歸、指標與人口資訊不懲罰

Ridge 是帶有係數平方懲罰的線性回歸，會把係數往較小的值拉，降低有限樣本下追逐雜訊的風險。alpha 是懲罰強度：較大時語音部分收縮更強。OLS 是普通最小平方法，只最小化平方誤差、不加這種係數懲罰。本專案的人口基準使用含截距、年齡與性別的 OLS；截距是提供整體平移的常數項。

除了主要 MAE，也報 RMSE 與 R²。RMSE 是平方誤差平均後開根號，會較重視大誤差；R² 是平方誤差相對於評分集合平均值參考的表現，負值表示平方誤差比該參考還差。三者不是同一目標，MAE 較低不保證 RMSE 或 R² 也較好。模型擬合使用平方損失，但 alpha 與層的選擇依 MAE，兩個目的也不能混為一談。

第一批普通 Ridge 把人口與語音係數一起懲罰。為控制高維語音而提高 alpha 時，人口項也可能被壓縮，使加入語音的模型連原有人口預測都保留不好。第二批改成只有語音係數受懲罰，人口項維持與人口基準相同的 OLS。

雙殘差法就是先扣除人口項可線性解釋的部分，再用剩餘語音預測剩餘目標。「殘差」是實際值扣除已擬合部分後的差。這裡不只對目標做殘差化，也對標準化後的每個語音特徵做，才能對應人口係數不受懲罰的共同模型。

設人口矩陣為 D、語音矩陣為 X、目標為 y。以下每個係數與統計量，都只從當次訓練資料取得：

1. 以訓練均值、標準差把 X 標準化為 Z，讓不同特徵的尺度可比較。
2. 擬合 y 對 D 的 OLS，係數記為 a；擬合 Z 對 D 的 OLS，係數記為 B。
3. 形成訓練殘差 r_y = y − Da、R_Z = Z − DB，對兩者擬合 Ridge，得到語音係數 β。
4. 對待預測的人，用訓練統計量形成 Z_new，預測為 D_new a + (Z_new − D_new B)β。

待評分集合的目標只用來算誤差，不能用來擬合 a、B、β 或標準化統計量。若先用完整開發資料殘差化再分折，評分折資訊就已進入前處理，不符合此流程。最終 test 的年齡、性別可作為預先指定輸入，但它的 BMI、身高不參與擬合。

### 共同交叉驗證與選 alpha

CV 是交叉驗證：輪流保留一部分開發資料評分，其餘用來訓練。每一次分出的訓練與評分組合稱為一折。本專案在 210 人中採依性別分層的 5 折 × 5 次重複，seed 為 42；分層讓各折性別比例不至於因隨機分配偏移。各折以 168 人擬合、42 人評分，沿用保存的完整 ID 分折。

OOF 是折外預測，指每個人的預測來自當次沒有以他訓練的模型。反覆交叉驗證有多次 OOF，但這些預測不是新增受試者。所有候選使用相同分折，才能看同一折內的成對差異。評分採 25 折 MAE 的平均，不先把同一人的重複預測平均成另一個分數。

每個目標、語音模型或層，各自在同一組 16 個 alpha、10^-3～10^12 中選平均 MAE 最低的設定。與最佳分數差不超過 10^-6 時取最大 alpha。這是預先固定的近似平手處理，讓幾乎相同分數偏向較強收縮，而不是看結果後另選喜歡的參數。

同一套 CV 同時用來調參與報分數，會使分數偏樂觀；再挑層會增加選擇機會。各折訓練資料互相重疊，25 個誤差不是獨立實驗，折間標準差與勝負次數只能描述，不把其標準誤拿來當嚴格顯著性證據。

### 選層、大 alpha 與鎖定

每層先依上述規則選 alpha，再取各層的平均 MAE。近似平手帶固定為 BMI 最低分＋0.05 kg/m²、身高最低分＋0.10 cm；帶內選最接近第 6 層者，同距離選較低層。這不是統計等效檢定、信賴區間或 one-standard-error rule（用分數標準誤決定較簡單設定的規則）。第 6 層只是固定偏好，沒有預設生理優勢。

嵌套檢查的意思是較大的模型包含基準模型作為特殊情況。本案 alpha 很大時，語音係數應接近消失，語音＋人口應退回同一人口 OLS；純語音模型則退回訓練目標平均值。使用 alpha=10^12，要求預測及 MAE 差小於 10^-6。這驗證程式與模型關係，不保證有限 alpha 的評分必然較好，也不是「巢狀交叉驗證」。

鎖定是把設定、分折、程式與輸入的版本先保存，再擬合。hash（雜湊值）像檔案內容的指紋，可辨識後續是否換了內容；它本身不證明科學結論。既有輸出拒絕覆寫，讓歷史階段可追溯。

### 正式 test 與不確定性

先固定兩目標、五模型、alpha、層及分析規則，再以全部 210 人重訓。預測階段只讀分離的可用輸入及開發目標，保存不含 test 目標的 270 筆預測。核對 ID、順序、有限值、範圍與 hash 後，才保存計分鎖並加入 135 人的 test 標籤。範圍核對只描述，不用來截斷、排除或改參數。

主要比較定義為 ΔMAE = MAE（選定 SSL＋人口）−MAE（人口），負值代表改善。10,000 次成對 speaker bootstrap，共用抽樣索引，seed=2026100503。個別 95% 使用 2.5%～97.5% 分位數；兩目標屬同一比較家族，另用 Bonferroni 多重比較門檻，也就是每個目標採 97.5% 雙側區間、1.25%～98.75% 分位數，上界小於零才通過。次要比較只作描述，不另增加確認性結論。來源：S2～S7。

## 6. 實驗歷程：做了什麼、為什麼、結果

### 第一批 validation：先讓最小流程做通

2026-10-04 保存完整特徵，但固定第 12 層，先只做 BMI 三模型。目的是先核對資料、特徵與評估能否接起來，降低在大量分析之後才發現對齊問題的成本。結果如下，原值取自 S1：

| 模型 | Alpha | Validation MAE（kg/m²） | RMSE（kg/m²） | R² |
|---|---:|---:|---:|---:|
| 年齡＋性別 | 0.001 | 3.237 | 4.020 | 0.047 |
| MFCC＋年齡＋性別 | 1000 | 3.374 | 4.092 | 0.012 |
| WavLM 第12層＋年齡＋性別 | 10000 | 3.313 | 4.028 | 0.043 |

語音模型都沒有超過人口基準；預測集中在 BMI 約 23 附近。這是當時普通共同懲罰 Ridge 與單一 validation 的結果，沒有不確定性分析，不足以推論整個 WavLM 無用。

### 修正懲罰並改用共同 CV

接著採人口不懲罰、雙殘差法與開發資料 CV，排除方法設計影響公平比較的可能。人口 OLS 的 CV MAE 為 2.940，MFCC＋人口為 2.940，WavLM 第12層＋人口為 2.854；SSL 選 alpha=1000，25 折中 16 折較好、9 折較差。50 個大 alpha 檢查通過。來源：S2。

同時做純語音性別診斷。它用不含年齡、性別的語音特徵分類性別，以檢查特徵是否攜帶基本可用訊號。LogisticRegression 是把線性分數轉為類別機率的分類模型；accuracy 是正確比例，balanced accuracy 則先在每一性別內算正確比例再平均，避免多數類別掩蓋弱項。MFCC 的兩項結果為 98.19%／98.29%，WavLM 第12層為 97.33%／97.91%。這支持基本訊號可用，但不證明同一性別內沒有錯配，也不保證 BMI 改善。

此輪 99 次性別內 BMI 置換仍只針對固定第 12 層與選 alpha。單次隨機標籤偶然勝過基準，不等於洩漏；完整搜尋的偏好仍需後續檢查。新舊結果同時改了懲罰和評估資料，不能把差額全歸因於其中一項。

### 加入診斷基準與身高

加入平均值、中位數與純語音，區分「能否擊敗簡單猜測」與「是否超過人口資訊」；再以身高檢查另一個目標。中位數是排序後的中央位置，比平均值較不受極端值影響。以下是固定第 12 層的開發 CV，不是正式 test。來源：S3。

| 模型 | BMI MAE（kg/m²） | 身高 MAE（cm） |
|---|---:|---:|
| 訓練折平均值 | 3.018 | 7.691 |
| 訓練折中位數 | 2.981 | 7.701 |
| 年齡＋性別（OLS） | 2.940 | 5.741 |
| MFCC 單獨 | 3.016 | 5.631 |
| WavLM 第12層單獨 | 2.835 | 5.547 |
| MFCC＋年齡＋性別 | 2.940 | 5.457 |
| WavLM 第12層＋年齡＋性別 | 2.854 | 5.596 |

BMI 的 MFCC＋人口選大 alpha，退回人口基準。身高在此輪有開發增益，且 MFCC＋人口分數較低，但還不能當作泛化結論。200 項大 alpha 檢查通過；原 BMI 三模型重現，確保擴充沒有改動原方法。

### 比較全部層並依固定規則選層

2026-10-05 改為每層各選 alpha，問最後一層是否限制了結果。來源 S4 的 comparison 原值如下：

### 檢查整個選擇過程的偶然增益

置換是把標籤隨機重新分配，觀察沒有原本標籤對應時仍能得到多好分數。每目標在性別內置換 99 次，重新擬合人口項、重選 alpha 與層，沿用原規則。這回檢查的是整套搜尋，不只固定層。下表增益為人口 MAE 減語音 MAE，正值較好，與正式 test 的 Δ 符號相反。來源：S5。

|---|---:|---:|---:|---:|

真實增益超過本次置換分布，但身高尾端有接近真實值的例子。性別內置換保留性別分組，仍破壞年齡與目標關聯，因此 0/99 不是正式條件式 p 值，也不是無洩漏證明。結果支持進入已鎖定 test，沒有拿它再調設定。

### 正式 test 與分組

先在 PRE_TEST_EXPECTATIONS 寫下增益可能縮小的預期、兩目標完整報告與區間門檻，再走先預測、後計分。BMI 的增益沒有縮小，身高縮小且未通過門檻；不能因對照不如期待就隱藏它。最後按性別、母語群描述誤差，辨識整體平均是否掩蓋群組差異。五模型、主要與次要比較、分組均預先固定，分組不反向選模型。來源：S6、S7。

## 8. 解讀與限制

首先，標籤與目標仍有距離。BMI 只描述身高體重的比例，實際體脂率有不同量測含義；目前的成功是 BMI 的有限預測增益。身高未確認額外增益也必須完整呈現，不能只留下較好看的目標。

其次，本研究驗證的是關聯，不是因果。母語群、通道或錄音條件可能與身體指標共同改變，固定模型仍可能利用它們。分組只能讓差異可見，沒有重新設計抽樣或控制干擾變數，也不能證明模型學到的是聲道長度、脂肪或特定生理機制。

單一資料集與有限獨立說話者，限制外推到其他年齡分布、收音裝置及錄音方式。錄音段數雖多，不能替代受試者數量；高維語音仍需要正則化。前段截取與平均也可能讓結果依賴錄音內容和可用片段，不能稱為充分利用了所有時間資訊。

bootstrap 只對固定模型和既有 test 人群重抽樣，沒有重新訓練、重分折或重選 alpha／層。因此區間不是整套研究流程的不確定性，也不是跨資料集泛化的保證。Bonferroni 採用的是近似 bootstrap 區間，不保證精確有限樣本涵蓋率。完整選擇置換也不是控制年齡後的正式檢定，不能把 0/99 當作強證明。

正式 test 已使用一次；設定因為 test 調整後，原測試就成為開發過程的一部分。不能再用它挑新模型，同時聲稱獲得新的無偏測試結果。原 validation、開發 CV 與正式 test 的樣本、訓練規模、懲罰方式及選擇用途不同，數字不能直接串成「模型每一輪進步多少」的曲線。來源：S2～S7。

## 9. 結論與建議的後續步驟

目前最穩健的結論是：在已鎖定的 NISP 流程下，選定 WavLM 語音特徵對 BMI 提供人口資訊以外的預測增益；身高額外增益未確認。這份實驗同時交代了成功、未成功、選擇偏差與可追溯程序，可作為專題方法和結果章的基礎。

後續先撰寫專題報告。口頭報告可按研究問題、人口捷徑、雙殘差與開發選擇、鎖定 test、主要結果、群組差異與限制的順序說明；既有圖表可作為輔助，不需要為文件整理再跑模型。

若另啟動方法研究，可在開發資料內規劃母語群留一群交叉驗證：每次以某母語群作評分資料，其餘群訓練，檢查跨群表現。留一群評估問的是能否移到不同群，與目前群內描述不同；仍需先規劃內部調參、人口基準及小群處理方式，不能偷偷借用已看過的 test。這是建議，尚未執行，不能寫成已有結果。

真正體脂率資料取得後，先確認量測方法、標籤單位、說話者對应、人口資訊、授權和切分，再建立獨立實驗與新的鎖定規則。可沿用本專案的資料隔離和比較原則，不能把 NISP 已選層及成績視為體脂率的驗證。來源：S0、S6；留一群流程為本文件的後續規劃，無結果數字。

### A. 名詞表

| 名詞 | 白話意思與本案用途 |
|---|---|
| MAE | 平均絕對誤差，每人偏差取絕對值再平均；本案主要選擇和比較指標。 |
| RMSE | 平方誤差平均後開根號，較敏感於大誤差；作補充指標。 |

| Ridge | 在線性回歸平方損失上加入係數平方懲罰；降低高維過度擬合風險。 |
| CV | 交叉驗證，在開發資料輪流訓練與評分；本案用來選設定。 |
| 折 | 一組訓練及評分的分配；重複折彼此不獨立。 |
| OOF | 折外預測，由當次未使用該人訓練的模型產生；不是正式 test。 |
| bootstrap | 有放回重抽受試者；成對版本讓兩模型共用同一抽樣。 |
| MFCC | 傳統頻譜形狀特徵；本案用係數的時間平均及標準差。 |
| WavLM | 預訓練語音表徵模型；本案凍結權重，逐層保存特徵。 |
| 殘差化 | 扣除人口項的線性預測；本案對目標與語音都做，係數只在訓練擬合。 |
| 嵌套檢查 | 確認大模型可退回基準；本案檢查大 alpha，不是巢狀 CV。 |
| OLS／標準化 | 不加懲罰的最小平方法／依訓練統計量調整特徵尺度。 |
| CI／Bonferroni | 信賴區間／同時比較多個目標時採用較嚴格門檻；本案預先指定。 |
